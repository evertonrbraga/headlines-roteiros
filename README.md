# Headlines e Roteiros

Cópia da skill pessoal `headlines-roteiros`, com instruções, referências editoriais e configuração do agente.

## Conteúdo

- `SKILL.md`: instruções principais.
- `agents/openai.yaml`: configuração do agente.
- `references/`: base de conhecimento, aprovações, direção visual e contrato de storyboard.

## Instalação

Clone este repositório em `~/.codex/skills/headlines-roteiros`.

A etapa de roteiro completo depende da skill irmã `roteiro`, instalada em `~/.codex/skills/roteiro`. Essa dependência é referenciada no arquivo original e não está incluída neste repositório.

Os 141 arquivos da skill foram preservados sem alterações. Caminhos locais e recursos externos mencionados nas instruções dependem do ambiente original.
